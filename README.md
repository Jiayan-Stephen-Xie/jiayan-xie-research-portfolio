# Jiayan (Stephen) Xie — Research Portfolio

English academic portfolio for Jiayan (Stephen) Xie, Duke Kunshan University, Class of 2027.

This GitHub Pages edition preserves the latest homepage layout, DKU affiliation logo, four research route cards, in-page navigation, online reading editions, and floating Home button.

The five PDF files are unchanged copies of the documents supplied for this portfolio. The homepage's View CV link opens a PDF hosted on this site. Document Download PDF buttons download files from the same site. All CSS, JavaScript and images are embedded in index.html; there are no Google-hosted resources required to display the portfolio or download its documents.

## 用 GitHub 网页发布

1. 登录 GitHub 账号 S7ephenXXX，新建 Public 仓库，名称填 jiayan-xie-research-portfolio，并勾选 Add README。
2. 解压 Jiayan-Xie-GitHub-Pages.zip。在仓库中选择 Add file → Upload files，上传解压目录内的 index.html、assets 文件夹和 README.md，提交到 main 分支。index.html 必须出现在仓库最外层；不要把 ZIP 本身当成网页上传。
3. 打开 Settings → Pages，将 Source 设为 Deploy from a branch，选择 main 和 /(root)，然后 Save。
4. 等待 Pages 页面出现 Visit site，再打开。按以上命名，预期访问地址是 https://s7ephenxxx.github.io/jiayan-xie-research-portfolio/ 。这是发布后的预期地址，本文件包本身尚未部署到 GitHub。
5. 在不连接 VPN 的大陆 Wi-Fi、手机流量及海外网络中测试，逐一点击 CV、摘要、报告和海报。GitHub Pages 的大陆可达性存在差异，迁移不能保证所有网络都正常。

压缩包还包含一个用于关闭 Jekyll 构建的标记文件。普通 HTML 和 assets 文件结构也支持 GitHub 默认的静态发布流程。

## 后续更新

网页正文、样式和脚本都在 index.html 中。更新 PDF 时，在 assets 中替换同名文件并提交。所有站内文件采用相对路径，可用于 GitHub 项目站点、个人站点，或其他静态托管平台。

当前 Google Sites 版本保持独立，不会随此发布包自动更新。此包根据本次对话最新源码生成，没有抓取或重新核对线上 Google Sites 页面。

## 访问范围与托管选择

GitHub Pages 可用于免费公开静态网站，但其网址在中国大陆可能出现无法连接、间歇性失败或访问缓慢。自定义域名也不保证改变底层网络可达性。如重点是大陆稳定访问，可将同一套文件部署到大陆托管并完成 ICP 备案；香港托管通常不需要大陆 ICP 备案，但仍需测试跨境线路。
